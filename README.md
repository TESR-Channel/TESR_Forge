# TESR Forge — Image & Present Tool

เครื่องมือจัดการรูปภาพและงานพรีเซนต์สำหรับทีม TESR — ใช้งานบนเบราว์เซอร์ ไฟล์เดียวจบ ไม่มีค่าบริการรายเดือน ไม่มี backend ข้อมูลไม่ออกจากเครื่องผู้ใช้

## ฟีเจอร์

- **อัปโหลดรูป** — เลือกไฟล์ หรือลากมาวางบนพื้นที่งาน (หลายรูปพร้อมกันได้)
- **ลบพื้นหลังด้วย AI** — คลิกเดียวจบ แบบเดียวกับ Remove Background ใน PowerPoint / Select Subject ใน Photoshop ใช้ได้กับสินค้า คน สัตว์ พื้นหลังซับซ้อน (โมเดล AI ทำงานในเบราว์เซอร์ โหลดครั้งแรก ~40MB แล้วเครื่องจำไว้ รูปไม่ถูกส่งขึ้นเซิร์ฟเวอร์) + โหมดจิ้มสีสำรองสำหรับตอนออฟไลน์ + ยางลบแบบแปรงเก็บขอบละเอียด
- **ปรับสีรูป** — สว่าง / คอนทราสต์ / สีสด / เฉดสี / เบลอ / คมชัด + ฟิลเตอร์ด่วน 6 แบบ (สตูดิโอ, จัดจ้าน, โทนอุ่น, โทนเย็น, ขาวดำ)
- **QR Code** — สร้างจากลิงก์/ข้อความ เลือกสี พื้นโปร่งใสได้ วางลงชิ้นงานหรือดาวน์โหลดแยก
- **วาด/ระบายสี** — ปากกาและมาร์กเกอร์ ปรับสี ขนาด ความทึบ
- **รูปทรง** — สี่เหลี่ยม วงกลม สามเหลี่ยม เส้น ลูกศร กรอบทอง
- **ข้อความไทย** — ฟอนต์ Prompt / Kanit / Sarabun หนา เอียง เงา จัดชิด
- **เลเยอร์** — เรียงลำดับ ซ่อน ลบ ทำสำเนา
- **เทมเพลตแบรนด์ TESR** — ภาพสินค้า / โพสต์โปรโมชัน / ปกคอร์ส Academy (โทนดำ‑แดง‑ทองตาม CI)
- **ขนาดงานตามของจริง** — งานพิมพ์ A5/A4/A3, นามบัตร, Roll-up, ไวนิล, Backdrop เวที (กำหนดเป็น ซม. + DPI ได้) และขนาดจอ TV/คอม Full HD, 4K — แถบสถานะบอกตลอดว่ากำลังทำงานที่ขนาดจริงเท่าไหร่
- **หลายหน้า (Pages)** — เพิ่ม/สำเนา/ลบหน้า ทำสไลด์พรีเซนต์ได้ในไฟล์เดียว
- **รองรับ GIF** — วาง GIF ลงงานได้ (หน้าจัดวางแสดงเฟรมแรก, ขยับจริงเมื่อ Export เป็น HTML/PowerPoint)
- **Export** — PNG (พื้นโปร่งใสได้) / JPG / **PDF** (หลายหน้า ส่งโรงพิมพ์ได้) / **PowerPoint (.pptx)** / **HTML Slideshow** / **วิดีโอ MP4/WebM** — เปลี่ยนสไลด์ทุกหน้าเป็นคลิป ตั้งวินาทีต่อหน้าได้ GIF ในงานขยับจริงในวิดีโอ — ความละเอียด 1×–3×
- **บันทึก/เปิดงาน** — ไฟล์โปรเจกต์ .json เอากลับมาแก้ต่อหรือส่งต่อให้เพื่อนร่วมทีมได้
- **คีย์ลัดครบชุด** — Ctrl+C คัดลอก · Ctrl+X ตัด · Ctrl+V วาง (รวมวางรูปที่ก๊อปมาจากนอกโปรแกรม เช่น screenshot/LINE) · Ctrl+D สำเนา · Ctrl+A เลือกทั้งหมด · Ctrl+G รวมกลุ่ม / Ctrl+Shift+G แยกกลุ่ม · Ctrl+Z/Y ย้อน-ทำซ้ำ · Ctrl+S บันทึกงาน · Ctrl+E เปิด Export · ลูกศรขยับทีละ 1px (Shift = 10px) · Delete ลบ · Esc ยกเลิกเลือก · V/B/T สลับเครื่องมือ
- **คลิกขวา** — เมนูครบ: คัดลอก วาง ตัด สำเนา มาหน้า/ไปหลังสุด จัดกึ่งกลาง รวม/แยกกลุ่ม ล็อกตำแหน่ง ลบ (การคัดลอกจะส่ง PNG เข้าคลิปบอร์ดระบบด้วย เอาไปวางใน LINE/PowerPoint ได้เลย)

## Deploy ขึ้น GitHub Pages

1. สร้าง repository ใหม่ เช่น `tesr-forge`
2. อัปโหลด `index.html` (และ `README.md`) ไว้ที่ root ของ repo
3. ไปที่ **Settings → Pages** → Source เลือก `Deploy from a branch` → Branch `main` / root → Save
4. รอ 1–2 นาที เปิดใช้ได้ที่ `https://<username>.github.io/tesr-forge/`

> ต้องออนไลน์ครั้งแรกเพื่อโหลดฟอนต์และไลบรารีจาก CDN (Fabric.js, qrcodejs)

## หมายเหตุการใช้งาน

- ลบพื้นหลัง AI ต้องออนไลน์ครั้งแรกเพื่อโหลดโมเดล หลังจากนั้นเบราว์เซอร์แคชไว้ ใช้ซ้ำได้เร็ว
- โหมดจิ้มสีเหมาะกับรูปพื้นเรียบและทำงานออฟไลน์ได้
- ก่อน Export รูปสินค้าพื้นโปร่งใส ให้กดปุ่ม **โปร่งใส** ที่แถบบน แล้ว Export เป็น PNG
- ไฟล์ทั้งหมดประมวลผลในเครื่องผู้ใช้ ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์
- งานป้าย/ไวนิลขนาดใหญ่ตั้ง DPI ต่ำ (34–50) ตามมาตรฐานงานพิมพ์ inkjet ระยะไกล — Export ที่ 2×–3× ได้หากโรงพิมพ์ต้องการไฟล์ละเอียดขึ้น
- ชิ้นงานจำกัดด้านละไม่เกิน 4096px เพื่อให้เบราว์เซอร์ทุกเครื่องทำงานลื่น
- Export วิดีโอ: Chrome/Edge ได้ .mp4 และเล่นเฟรม GIF เต็มรูปแบบ เบราว์เซอร์อื่นได้ .webm และ GIF อาจเป็นภาพนิ่ง — การอัดใช้เวลาเท่าความยาวคลิปจริง
